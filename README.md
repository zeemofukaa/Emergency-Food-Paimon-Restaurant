## ૮₍ ˃ ⤙ ˂ ₎ა Emergency Food | Paimon Restaurant

A fantasy-themed full-stack restaurant web app inspired by the world of Teyvat (Genshin Impact).
Built with HTML, CSS, JavaScript, Node.js, Express, and MongoDB.

This project focuses on immersive UI design, dynamic rendering, authentication, persistent user data, and interactive user experience rather than a traditional food-ordering layout.

🔗 **Live Website:** [Emergency Food | Paimon Restaurant](https://emergency-food-paimon-restaurant.onrender.com)

---

✦ **Features**

• Dynamic menu rendering using JSON data

• Categorized food sections (Starter, Main Course, Desserts, Drinks)

• Responsive design for desktop and mobile

• Interactive shopping cart system

• Quantity controls & cart item management

• Animated mobile navigation menu

• Fantasy-themed UI inspired by Teyvat

• Dynamic DOM rendering instead of repetitive static HTML

• User authentication (Login / Signup)

• Persistent cart storage using MongoDB

• Order placement and order history tracking

• Table reservation system

• Reservation history

• Reservation cancellation

• Backend-driven menu APIs

• Secure JWT authentication

✦ **Inspiration**

Inspired by the food system, ambience, and fantasy atmosphere of Genshin Impact.

The UI design focuses on creating a cozy fantasy tavern / restaurant experience rather than a conventional food-delivery interface.

---

✦ **Notes**

This project originally started as a first-year frontend-only restaurant website and was later refactored into a scalable full-stack application.

The focus is on improving architecture, maintainability, UI design, and backend integration.
